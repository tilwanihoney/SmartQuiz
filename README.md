# 🎯 SmartQuiz

An interactive Quiz Management System developed using Django.

## 📌 Features

- User Registration & Login
- Quiz Categories
- Multiple Choice Questions
- Score Calculation
- Result Page
- Admin Dashboard
- Responsive User Interface

## 🛠️ Technologies Used

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite

## 📂 Project Structure

```
SmartQuiz
│── smartquiz/
│── myapp/
│── templates/
│── static/
│── manage.py
│── db.sqlite3
```

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/tilwanihoney/SmartQuiz.git
```

Go to the project folder

```bash
cd SmartQuiz
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the server

```bash
python manage.py runserver
```

Open your browser

```
http://127.0.0.1:8000/
```
